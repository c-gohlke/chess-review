# chess-review

Find the mistakes you keep making, and train them away.

Beginners lose most of their games to the same handful of errors: hanging a piece, ignoring a threat, missing a one-move tactic. Game review tools show you each blunder in isolation. This project connects the dots across your games and turns your recurring mistakes into personalised puzzles.

## Planned scope

1. Import games from Lichess, Chess.com or PGN files.
2. Analyse them with Stockfish and flag mistakes.
3. Classify each mistake into a beginner-friendly theme.
4. Aggregate across games to surface the patterns you repeat.
5. Generate puzzles from those positions and schedule them for review.
